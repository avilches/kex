# Agent Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third Action kind, `agent`, that opens a new terminal tab per click, with presets from the scan and one-time seeding.

**Architecture:** `Action.runInTerminal` becomes `kind: "app" | "script" | "agent"` with three pure predicates. Runner planning stays pure in `actionRun.ts` with a new `new-agent-tab` plan. Rust `editor_scan` also returns agents (built from `DEFAULT_AGENTS`) tagged `kind: "agent"`; presets and seeding are pure functions on the frontend.

**Tech Stack:** React 19, TypeScript, Vitest, Tauri 2 / Rust, pnpm.

**Spec:** `docs/superpowers/specs/2026-10-24-agent-actions-design.md` (task TASK-897).

## Global Constraints

- No em-dash, no emojis anywhere (code, comments, docs, commits).
- No backward compatibility, migration, shim or fallback for `runInTerminal`. Stored Actions in the old shape are dropped by `normalizeAction`.
- Comments: default none; at most 1-2 lines of why.
- Imports always `@/...` across modules; IDs only via `newActionId()`.
- pnpm only. Commits atomic, in English, one line, no `Co-Authored-By`, no "Generated by".
- The agent name list lives only in Rust `DEFAULT_AGENTS` (`src-tauri/src/modules/agent/launch_cmd.rs`).
- Agent command is the bare binary (`claude`); variants differ by `cwdMode` (`workspace` / `context`), never by command text.
- Checks before done: `pnpm lint`, `pnpm check-types`, `pnpm test`, `cd src-tauri && cargo clippy && cargo test --locked`.
- Docs in the same commit as the change: `docs/ARCHITECTURE.md`, `docs/IPC.md`, `docs/FORK.md`, and the **Action** glossary row in `CLAUDE.md`.

## Review Focus

- Clicking the same agent Action twice must open two tabs, never focus or reuse the first.
- Removing seeded agents and restarting must not re-seed; a scan that finds no agents must not set the flag.
- Two windows scanning at once must not seed twice.
- An agent installed after seeding appears in the combo only, and installing `{cwd}` leaves `{workspace}` offered.
- A detected agent must never appear as an editor anywhere (Open in, editor lists).
- An agent with a value containing `$`, quotes, backtick or backslash is rejected like a script.
- Old-shape stored Actions (with `runInTerminal`, no `kind`) are dropped, not guessed.
