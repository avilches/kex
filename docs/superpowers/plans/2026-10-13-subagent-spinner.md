# Spinner mientras haya subagentes en segundo plano: plan de implementacion

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mientras haya subagentes en segundo plano ocupados, la sesion del agente se queda en `working` (spinner) y el aviso amarillo solo sale cuando todo ha terminado.

**Architecture:** Dos hooks nuevos de Claude Code (`SubagentStart`, `SubagentStop`) llegan por el socket a `ipc.rs`, que los emite como senales; el `Stop` lleva ademas la lista de subagentes vivos. El store guarda un registro por subagente en cada sesion, y una funcion pura decide el estado que produce un `Stop`. La UI no cambia: `buildAgentEntries` ya pinta el spinner para `working`.

**Tech Stack:** Rust (Tauri, serde_json), TypeScript, React 19, zustand, vitest.

**Spec:** `docs/superpowers/specs/2026-10-13-subagent-spinner-design.md`

## Review Focus

- Un `SubagentStart` que llega con la sesion todavia sin registrar (Kex arranca a mitad de turno): debe crearla, no perderse.
- Un `Stop` sin campo `background_tasks` o con entradas que no son `subagent` (tareas de otro tipo): no deben contar como subagentes.
- Un `Stop` cuya lista trae entradas con `status` distinto de `running`: no cuentan.
- Dos `SubagentStart` seguidos con el mismo `agent_id`: no duplican el registro ni pisan su `startedAt`.
- Un `SubagentStop` de un `agent_id` desconocido, o de un tab sin sesion: no rompe nada.
- El `Stop` final con lista vacia limpia un registro que quedo colgado por un `SubagentStop` perdido.

`subagentGate.ts`:

```ts
import type { AgentStatus, BackgroundSubagent, SubagentRecord } from "./types";

/** The status a turn-ending Stop produces: background subagents keep the agent working. */
export function stopOutcome(activeSubagents: number, tabSeen: boolean): AgentStatus {
  if (activeSubagents > 0) return "working";
  return tabSeen ? "idle" : "attention";
}

/** Replace the known subagents with the list a Stop reports, keeping what is still running. */
export function reconcileSubagents(
  prev: Record<string, SubagentRecord>,
  list: BackgroundSubagent[],
  now: number,
): Record<string, SubagentRecord> {
  const next: Record<string, SubagentRecord> = {};
  let changed = list.length !== Object.keys(prev).length;
  for (const sub of list) {
    const known = prev[sub.id];
    const description = sub.description || known?.description;
    next[sub.id] = {
      agentType: sub.agentType || known?.agentType || "",
      description,
      startedAt: known?.startedAt ?? now,
    };
    if (!known || known.description !== description || known.agentType !== next[sub.id].agentType) {
      changed = true;
    }
  }
  return changed ? next : prev;
}
```
